# FRZFRM Weather Catch

Catch the real weather where you are, and fill a shelf of living jars.

Test version 0.16.0. Play it at https://frzfrmg.github.io/FRZFRM-weather-catch/

- Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0)
- Place names from [BigDataCloud](https://www.bigdatacloud.com/)
- Animals are recognised on the phone with [OpenCLIP](https://github.com/mlfoundations/open_clip) (ViT-B/32 trained on LAION-2B, MIT licence). The 8-bit model files in `spotter/` were converted from the ONNX export in [Tidy](https://github.com/slavabarkov/tidy).
